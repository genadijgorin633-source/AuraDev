# LYNX Curators — TM PROJECT
Демонстрационный сайт-кураторка с интерактивным каталогом и синей неоновой дизайн-системой.

## Запуск
Откройте \`index.html\` локально либо используйте GitHub Pages в репозитории AuraDev, путь \`/lynix_curator/\`.

## Разделы
- Главная: бренд, метрики, популярные материалы, инструменты и категории.
- Материалы: поиск, фильтры по категориям/формату/сложности, сортировка, избранное.
- Статья: структура урока, содержание, закладки, переходы между уроками.
- Инструменты: каталог сервисов, поиск, категории, внешние ссылки, избранное.
- Статистика: демо-метрики и графики.
- О проекте: информация и FAQ.
- Ctrl+K: глобальный поиск. Адаптивная версия для мобильных.

## Важно
Статистика и учебный контент сейчас демонстрационные. Авторизация, оплата и реальный бэкенд не подключены. Закладки сохраняются локально на устройстве.

## Файлы
index.html — каркас, styles.css — стили, app.js — логика, assets/mark.svg — фирменный векторный знак, assets/brand.svg — векторный логотип, assets/scene.svg — векторный декоративный фон.

## Размещение
Код расположен только в папке \`lynix_curator/\`, файлы остальных проектов не менялись.
