# LYNX Curators

Сайт на HTML, CSS и JavaScript. Без сборщика и сервера приложений.

## Новый главный экран

- По центру — **LYNX Curators**, ниже **«Выбор направления»**.
- Четыре равные карточки: **NFT**, **Trade**, **Escort**, **Transfer**.
- Отдельная страница каждого направления: `#/direction/nft`, `#/direction/trade`, `#/direction/escort`, `#/direction/transfer`.
- Шапка: Направления, Материалы, Инструменты, Сообщество. Кнопки входа нет.
- Адаптивный дизайн для смартфонов.

## Ассеты

Исходные композиции были сгенерированы отдельно и оптимизированы для сайта.

- `assets/directions/desktop-bg.avif` — новый космический фон для компьютера.
- `assets/directions/mobile-bg.avif` — вертикальная мобильная версия.
- `assets/directions/nft.avif`, `trade.avif`, `escort.avif`, `transfer.avif` — отдельные иллюстрации карточек.
- Одноимённые SVG доступны как векторные запасные варианты.

В изображениях нет кошки и персонажа на фоне. Изображения в карточках отделены от HTML-текста, поэтому заголовки и описания можно менять без перегенерации графики.

## Остальные разделы

`#/materials`, `#/tools`, `#/statistics`, `#/about`. Это демонстрационная версия: настоящей авторизации, специальных ботов и реальной статистики пока нет.

## Запуск

Откройте `index.html` или включите GitHub Pages из `main` для репозитория `AuraDev`. Адрес каталога: `/AuraDev/lynix_curator/`.

## Аудит

После изменения страниц GitHub Actions создаёт desktop/mobile скриншоты и проверяет ширину страницы, загрузку изображений и обрезку текста: `audit/`.
