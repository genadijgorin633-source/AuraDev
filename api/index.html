01
Overview

Обзор

Текущий публичный API уже использует /api/v1, Bearer-ключи и единый JSON-формат. vNext сохраняет эту модель и расширяет её без необходимости строить отдельную интеграцию под каждый продукт.

i
COMPATIBILITY

Существующие рабочие маршруты можно оставить без изменений, а новые добавлять рядом по мере готовности backend.

02
Authentication

Авторизация

Каждый приватный запрос передаёт ключ в HTTP-заголовке.

Authorization: Bearer sw_live_••••••••••
!
SECURITY

API key должен храниться только на backend. Не помещайте его в browser JavaScript, публичные репозитории или клиентские конфиги.

03
Billing

Баланс и пополнение

GET/api/v1/balanceLIVE

Возвращает баланс владельца API-ключа.

{ "ok": true, "balance": 42.5, "balance_label": "42.50 USDT", "purchases": 12 }
POST/api/v1/billing/invoicesDESIGN

Создаёт счёт для пополнения баланса и возвращает URL оплаты.

{ "amount": 100, "provider": "xrocket" }

→ { "invoice_id": "inv_8K21", "amount": "100.00 USDT", "payment_url": "https://..." }
04
Accounts

Каталог аккаунтов

GET/api/v1/accounts/categoriesDESIGN

Возвращает доступные категории маркета.

Физический · НовыйЧистые аккаунты.clean
Возрастные1–7 лет.aged_1y … aged_7y
Shadow SRZОтдельная категория.shadow_srz
CountriesФильтрация по доступным странам.country=RU
GET/api/v1/accounts/stock?category=cleanDESIGN

Остатки, минимальные цены и страны для выбранной категории.

{ "items": [{ "country": "ru", "price": 1.90, "quantity": 120 }], "total_quantity": 120 }
05
Purchase

Покупка аккаунтов

POST/api/v1/accounts/purchaseDESIGN

Покупает один или несколько аккаунтов из выбранной категории и страны.

curl -X POST https://api.swiftsms.xyz/api/v1/accounts/purchase \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"category":"clean","country":"RU","quantity":3,"sort":"cheap"}'
{ "ok": true, "order_id": "ord_82K1", "quantity": 3, "total_price": 5.70, "account_ids": [1001,1002,1003] }

07
Telethon

Экспорт Telethon .session

Файлы можно отдавать бинарным HTTP-ответом. Для массовой выгрузки удобнее ZIP: клиентский сервер получает архив и сохраняет его напрямую.

GET/api/v1/accounts/{id}/sessionDESIGN

Скачивание одного .session файла.

Content-Type: application/octet-stream
Content-Disposition: attachment; filename="79990000000.session"
POST/api/v1/accounts/sessions/exportDESIGN

Массовая выгрузка купленных аккаунтов одним ZIP-архивом.

{ "account_ids": [1001,1002,1003] }

→ application/zip · swift_sessions_82K1.zip

Login codes

Получение Telegram-кода

14
Reliability

Idempotency и лимиты

Для денежных POST-запросов стоит поддержать Idempotency-Key, чтобы повтор после timeout не создавал вторую покупку.

Idempotency-Key: 7a09f3f0-8c1c-4d31-985e-...
↻
RECOMMENDED

Одинаковый ключ + одинаковое тело запроса возвращают тот же результат в пределах окна идемпотентности.
