Пользовательское соглашение

Настоящее соглашение определяет порядок использования Telegram-бота SwiftShop, приобретения цифровых товаров и взаимодействия с сервисом.

Начиная использование бота SwiftShop, пользователь подтверждает, что прочитал, понял и полностью принимает настоящее соглашение.

01

Общие положения

Настоящее Пользовательское соглашение регулирует отношения между сервисом SwiftShop, далее — «Сервис», и лицом, использующим Telegram-бот SwiftShop, далее — «Пользователь».

Актуальный Telegram-бот Сервиса доступен по адресу https://t.me/SWIFT_SMS_roBOT.

Использование бота, его функций, пополнение баланса либо приобретение любого товара или услуги означает полное и безоговорочное принятие настоящего соглашения.

Если Пользователь не согласен с условиями соглашения, он обязан прекратить использование Сервиса.

02

Термины

Сервис — Telegram-бот SwiftShop, его программные компоненты, база данных и интерфейсы.

Пользователь — любое лицо, которое открыло бота, использует его функции либо совершило оплату.

Товар — цифровой объект, данные доступа, аккаунт, прокси, VPN-доступ, Telegram Premium, медиапак или иной цифровой продукт, размещенный в Сервисе.

Баланс — внутренний учет денежных средств Пользователя, доступных для оплаты товаров и услуг внутри Сервиса.

03

Предмет соглашения

Сервис предоставляет Пользователю техническую возможность просматривать, оплачивать и получать цифровые товары и услуги, доступные в интерфейсе бота.

Ассортимент, наличие, характеристики и стоимость товаров указываются в боте на момент оформления покупки.

Сервис вправе изменять ассортимент, стоимость, описание и условия предоставления товаров без предварительного уведомления Пользователя.

04

Доступ к сервису

Для использования Сервиса необходим действующий аккаунт Telegram.

Пользователь самостоятельно отвечает за сохранность доступа к своему Telegram-аккаунту, устройствам, кодам подтверждения и иным данным авторизации.

В случае потери доступа к Telegram-аккаунту перенос внутреннего баланса и ранее приобретенных аккаунтов может быть выполнен только после обращения в поддержку и успешного подтверждения принадлежности данных Пользователю.

Решение о возможности переноса принимается Сервисом на основании доступной информации.

05

DEV API

SwiftShop может предоставлять Пользователю DEV API key для серверных интеграций, автоматической проверки баланса, покупки аккаунтов и получения кодов через API.

DEV API key является конфиденциальным средством доступа. Пользователь обязан хранить его как пароль, не публиковать, не передавать третьим лицам, не размещать в клиентском JavaScript, публичных репозиториях, логах, скриншотах и иных общедоступных местах.

Все действия, выполненные с использованием действительного DEV API key Пользователя, включая покупки, списания баланса, запросы кодов и просмотр данных аккаунтов, считаются действиями самого Пользователя.

В случае компрометации, утраты или подозрения на передачу ключа третьим лицам Пользователь обязан немедленно пересоздать ключ в разделе «Информация → DEV API». Пересоздание ключа автоматически отзывает старый ключ, после чего старый ключ перестает работать.

Сервис не несет ответственности за последствия действий, совершенных с использованием действительного ключа Пользователя, если такие действия стали возможны вследствие разглашения, утраты или небезопасного хранения ключа Пользователем.

06

Товары и услуги

Через Сервис могут предоставляться Telegram-аккаунты, прокси, VPN-доступ, Telegram Premium, а также цифровые паки фотографий и видеосообщений.

Все товары являются цифровыми и передаются Пользователю в электронном виде. Физическая доставка не осуществляется.

Цифровые материалы, полученные из открытых источников, предоставляются в том виде, в котором они были доступны на момент формирования соответствующего пака.

Перед покупкой Пользователь обязан ознакомиться с описанием товара, его параметрами, ценой и иной информацией, указанной в карточке товара.

Сервис не предоставляет гарантию бессрочной работоспособности сторонних платформ, аккаунтов, прокси, VPN-соединений и иных цифровых продуктов после их получения, если проблема возникла вследствие действий Пользователя, правил стороннего сервиса или обстоятельств вне контроля SwiftShop.

07

Оплата и баланс

Оплата внутри Сервиса может осуществляться через платежные решения @send (CryptoBot) и @xRocket, а также другими способами, доступными в интерфейсе бота.

Данные платежа, необходимые для создания счета, проверки оплаты и зачисления баланса, обрабатываются внешними платежными провайдерами @send и @xRocket по их собственным правилам.

После успешного пополнения сумма зачисляется на внутренний баланс Пользователя.

Внутренний баланс не имеет срока действия и не сгорает.

Вывод средств с внутреннего баланса не предусмотрен. Передача баланса другому Пользователю не допускается, кроме переноса при подтвержденной потере доступа к прежнему Telegram-аккаунту.

При возникновении проблемы с оплатой, зачислением или выдачей товара Пользователь должен обратиться в поддержку и предоставить сведения, необходимые для проверки платежа.

08

Возврат средств

Возврат средств возможен только при наличии подтвержденной проблемы со стороны Сервиса.

Основанием для рассмотрения возврата может являться:

  • полученный товар существенно не соответствует описанию;
  • товар не является рабочим в момент его выдачи;
  • оплата была получена, но товар не был выдан по технической причине со стороны Сервиса.

Возврат не производится, если проблема возникла после выдачи товара вследствие действий Пользователя, изменения данных, нарушения рекомендаций, блокировки сторонней платформой, утраты доступа или передачи товара третьим лицам.

Для рассмотрения обращения Пользователь обязан связаться с поддержкой и предоставить доказательства оплаты и описание проблемы.

Решение по обращению принимается после технической проверки обстоятельств.

Пользователь обязан самостоятельно учитывать правила Telegram, платежных сервисов, поставщиков VPN и прокси, а также требования, действующие по месту его нахождения.

Сервис не контролирует действия Пользователя после передачи товара и не является участником дальнейших операций, совершаемых с использованием приобретенного продукта.

Все последствия использования товара, включая ограничения, блокировки, потерю доступа, претензии третьих лиц и иные риски, несет Пользователь, если они не вызваны доказанной технической ошибкой Сервиса.

Сервис не несет ответственности за блокировку Telegram-аккаунта, изменение правил Telegram или иной сторонней платформы, потерю доступа, удаление данных, ограничение функциональности, изменение IP-адресов, перебои VPN или прокси, если такие события находятся вне прямого контроля SwiftShop.

Сервис не отвечает за убытки, упущенную выгоду, потерю данных, репутационные последствия и иные косвенные убытки Пользователя.

Работа Сервиса может временно ограничиваться из-за технического обслуживания, ошибок, сбоев Telegram, платежных провайдеров, хостинга, сетевой инфраструктуры или иных внешних обстоятельств.

Сервис не гарантирует непрерывную и безошибочную работу бота, однако принимает разумные меры для восстановления его доступности.

11

Данные пользователя

Для работы Сервиса могут обрабатываться Telegram ID, username, история покупок, внутренний баланс, сведения о платежах, технические журналы и иные данные, необходимые для функционирования бота, выдачи товаров и поддержки Пользователей.

Пользователь соглашается на обработку указанных данных в объеме, необходимом для предоставления функций Сервиса.

Сервис принимает разумные технические меры для защиты данных, однако не может гарантировать абсолютную защищенность информации от всех возможных угроз.

Данные обрабатываются для авторизации Пользователя, исполнения покупок, учета баланса, предотвращения злоупотреблений, обработки обращений и проверки платежей. Они могут храниться в течение срока, необходимого для этих целей и исполнения применимых требований.

Для обработки платежей и работы Telegram отдельные сведения могут передаваться соответствующим платежным провайдерам и Telegram в объеме, необходимом для выполнения операции. Такие лица обрабатывают данные по собственным правилам конфиденциальности.

По вопросам обработки данных, их уточнения или удаления Пользователь может обратиться в техническую поддержку. Возможность удаления отдельных сведений может быть ограничена, если их хранение необходимо для учета операций, разрешения споров или исполнения требований закона.

Новая редакция вступает в силу с момента ее публикации на данной странице либо с иной даты, прямо указанной в тексте обновления.

Продолжение использования бота после публикации новой редакции означает согласие Пользователя с обновленными условиями.

Все обращения и спорные ситуации рекомендуется первоначально направлять в техническую поддержку SwiftShop.
