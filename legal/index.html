General

Общие положения

Настоящее Пользовательское соглашение регулирует отношения между сервисом SwiftShop и лицом, использующим его интерфейсы, Telegram-бота, веб-сервисы либо DEV API.

Используя SwiftShop, пользователь подтверждает, что ознакомился с настоящим соглашением, понимает его содержание и принимает изложенные условия.

02
Terms

Термины

Сервис — SwiftShop, включая его программные компоненты, интерфейсы и интеграции.

Пользователь — лицо, использующее функции сервиса или совершающее операции через него.

Цифровой товар — цифровой объект, данные доступа, аккаунт, прокси, VPN-доступ, медиаматериал или иной продукт, предоставляемый электронно.

03
Agreement subject

Предмет соглашения

SwiftShop предоставляет техническую возможность просматривать, оплачивать и получать доступные цифровые товары и услуги, а также использовать связанные сервисные функции.

Ассортимент, наличие, характеристики и стоимость определяются интерфейсом SwiftShop на момент совершения операции.

04
Service access

Доступ к сервису

Для отдельных функций может потребоваться авторизация через Telegram, веб-аккаунт или иной доступный способ идентификации.

Пользователь самостоятельно отвечает за сохранность учётных данных, устройств, кодов подтверждения и иных средств доступа.

05
Developer access

DEV API

SwiftShop может предоставлять DEV API key для серверных интеграций, автоматизации операций и доступа к поддерживаемым функциям сервиса.

Все действия, выполненные с использованием действительного API key пользователя, рассматриваются как действия соответствующей учётной записи.

◇
SECURITY NOTE

DEV API key следует хранить как пароль. Не публикуйте ключ в JavaScript, публичных репозиториях, логах или скриншотах.

06
Products

Товары и услуги

Через SwiftShop могут предоставляться цифровые товары и сервисы, доступные в интерфейсе на момент покупки.

Перед покупкой пользователь обязан ознакомиться с описанием, параметрами, ценой и условиями передачи товара.

07
Payments

Оплата и баланс

Внутренний баланс может использоваться для оплаты поддерживаемых товаров и услуг. Платёжные провайдеры могут применять собственные комиссии и правила обработки транзакций.

08
Refunds

Возврат средств

Возможность возврата определяется характером цифрового товара, фактом его передачи и обстоятельствами конкретной операции.

09
Responsibility

Ответственность пользователя

Пользователь обязан использовать SwiftShop законно, не нарушать права третьих лиц и не предпринимать действий, направленных на нарушение работы сервиса.

10
Service responsibility

Ответственность сервиса

SwiftShop стремится поддерживать доступность функций, но не гарантирует абсолютную бесперебойность сторонних платформ, сетей и провайдеров.

11
Data

Данные пользователя

SwiftShop обрабатывает данные, необходимые для авторизации, выполнения операций, обеспечения безопасности и поддержки пользователей.

12
Changes

Изменение соглашения

SwiftShop вправе обновлять настоящее соглашение по мере развития сервиса, изменения функциональности или требований безопасности.

13
Final

Заключительные положения

Если отдельное положение соглашения становится неприменимым, остальные положения продолжают действовать в максимально допустимом объёме.

Contact
